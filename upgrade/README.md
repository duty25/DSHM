# DSHM 同包名覆盖升级

目标是com.siliconleap.app的v2.1.43，不是独立预览App。保留原生主界面、3082、现有运行时与本地数据，不重装/迁移插件账号，不强制安装Linux。

构建只读取既有公开APK并核对SHA256，复用其JNI原生库；签名必须由仓库既有ANDROID_* Secrets提供且与旧包证书一致。不接受debug或内嵌私钥兜底，不发布Release，不写主分支。升级包还会核对包名、versionCode、签名、所有原生库与不携带替换运行时。

保留stability-v1、token/cookie兼容、共享存储与原生维护钩子，启动日志不再输出完整profile正文或在Toast展示token。网页入口404/5xx不再判成功。未来App内更新会先拒绝不同包名/降级/不同签名，不要求卸载或清数据。

签名与旧公开Release匹配不等于已经实时读取手机PackageManager。系统安装器仍会核对实际安装证书；普通应用环境不能静默代按安装确认。安装前保存正在执行的任务，任何不匹配应停止，不能以卸载或清数据强装。
